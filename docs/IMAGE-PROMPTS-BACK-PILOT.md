# Open Massage Guide — Pilot prompts for back images

Ниже — стартовые промпты для трёх пилотных изображений.

Общие требования для всех трёх:

- clean medical massage illustration;
- vertical 4:5 composition;
- final target size 1200x1500;
- no text labels;
- no paragraphs or UI elements;
- soft neutral background;
- clear hands and correct finger anatomy;
- visible motion arrows;
- suitable for both Russian and English card text.

---

## 1. back-001

**ID:** `back-001`  
**Category:** `back`  
**Idea:** gentle longitudinal stroking of the back.

### Prompt

Create a clean professional medical-style massage illustration for an educational guide. Show an adult person lying face down, back fully visible from above in a centered vertical composition. Show the practitioner’s two hands placed on the back performing gentle longitudinal stroking along the large back muscles. The motion should clearly travel upward along the back in long smooth lines. Add elegant blue directional arrows indicating the hand movement. Highlight the general back area softly, without text. The anatomy must be calm, neutral, professional, and non-sexual. Use a light neutral background, clean contours, soft shading, and correct finger anatomy. No text labels, no icons, no decorative clutter.

## 2. back-004

**ID:** `back-004`  
**Category:** `back`  
**Idea:** circular rubbing on the back.

### Prompt

Create a clean professional medical-style massage illustration for an educational guide. Show an adult person lying face down with the full back visible in a centered vertical composition. Show the practitioner’s hands performing circular rubbing over the muscular areas of the upper and mid back. Add clear but subtle circular blue arrows over the working zones to show the movement pattern. Emphasize soft tissue work, not deep pressure on the spine. Keep the scene neutral, educational, and professional. Use a light neutral background, clean borders, soft realistic shading, correct hand anatomy, and no text labels. The image should be suitable for both Russian and English versions of the technique card.

## 3. back-012

**ID:** `back-012`  
**Category:** `back`  
**Idea:** finishing stroking of the back.

### Prompt

Create a clean professional medical-style massage illustration for an educational guide. Show an adult person lying face down with the full back visible from above in a centered vertical composition. Show the practitioner’s two hands performing very light finishing strokes over the back with long calming movement paths. Add soft blue directional arrows that show the final smoothing motion, with a calm and gentle visual tone. The image should look like the finishing stage of a massage sequence. Use a light neutral background, clean contours, soft shading, and anatomically correct hands. No text labels, no symbols, no extra clutter. The illustration must remain language-neutral and suitable for both Russian and English card content.
