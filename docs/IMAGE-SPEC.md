# Open Massage Guide — IMAGE SPEC v1

Статус: `approved draft`

Этот документ фиксирует единый стандарт изображений для проекта **Open Massage Guide**.

---

## 1. Цель

Изображения должны:

- визуально поддерживать карточки техник;
- быть пригодными одновременно для `ru` и `en` локалей;
- быстро загружаться в PWA;
- хорошо выглядеть на мобильных устройствах;
- оставаться единообразными по стилю во всём проекте.

---

## 2. Основные правила

1. **Одна техника = одно изображение**.
2. **Одно изображение используется для обеих локалей (`ru` / `en`)**.
3. **Текст внутрь изображения не встраивается**.
4. Допускаются только:
   - стрелки направления движения;
   - мягкая подсветка рабочей зоны;
   - визуальное положение рук;
   - дополнительные простые графические элементы без языка.
5. Изображение должно быть понятно без длинных подписей.
6. Каждое изображение должно соответствовать конкретному `id` карточки.

---

## 3. Формат файлов

### Финальный формат

- **формат:** `webp`
- **режим:** lossy WebP
- **качество:** ориентир `80`
- допустимый рабочий диапазон: `75–85`

### Размер

Базовый стандарт:

- **1200 × 1500 px**
- вертикальный формат
- соотношение сторон: **4:5**

### Ориентир по весу файла

- целевой размер: **100–300 KB**
- допустимо больше, если схема сложная, но желательно не раздувать каталог без необходимости

---

## 4. Визуальный стиль

### Общий стиль

- clean medical massage illustration
- учебная инфографика
- мягкая профессиональная подача
- без агрессивного фотореализма
- без перегруза мелкими деталями
- аккуратная анатомия
- ровная композиция

### Палитра

- фон: светлый, тёплый, нейтральный
- кожа: естественные мягкие оттенки
- стрелки: спокойные, хорошо читаемые
- акцентные зоны: мягкая подсветка, не кислотная

### Фон

- однотонный или очень нейтральный
- без интерьерных деталей
- без мебели, если это не нужно для понимания техники

---

## 5. Композиция

Для большинства карточек используется единый принцип:

- тело или зона массажа занимает основную часть изображения;
- руки массажиста чётко видны;
- рабочая зона читается сразу;
- стрелки направления движения располагаются поверх рабочей области;
- композиция не должна быть перегружена.

### Предпочтительный шаблон

**Одна большая схема без текстовых подписей**, где есть:

- анатомическая область;
- руки;
- стрелки;
- мягкий визуальный акцент на зоне воздействия.

---

## 6. Анатомические требования

Обязательно:

- нормальная анатомия кистей;
- корректное количество пальцев;
- естественные пропорции;
- понятный контакт рук с телом;
- отсутствие неестественных поз;
- направление движений должно соответствовать технике.

Недопустимо:

- деформированные пальцы;
- лишние или слипшиеся пальцы;
- неясное положение кистей;
- нелогичные направления стрелок;
- работа по анатомически неверной зоне.

---

## 7. Языковая нейтральность

Изображение должно подходить одновременно для:

- `ru.json`
- `en.json`

Поэтому в саму картинку **не добавляем**:

- русские подписи;
- английские подписи;
- заголовки;
- пояснительные абзацы.

Вся текстовая информация остаётся в JSON-контенте карточек.

---

---

## 9. Связь с `meta.json`

До публикации:

```json
{
  "image": null,
  "status": "draft"
}
```

После публикации:

```json
{
  "image": "./assets/images/techniques/back/back-001.webp",
  "status": "published"
}
```

## 10. Порядок приоритета по производству

### Пилот

Сначала делаем 3 тестовые изображения:

1. `back-001`
2. `back-004`
3. `back-012`

### Затем пакетами

1. `back-001 ... back-012`
2. `neck-001 ... neck-012`
3. `arms`, `legs`, `feet`
4. `face-head`, `self-massage`, `programs`, `safety`

---

## 11. Контроль качества

Перед публикацией каждое изображение проверяется по чеклисту:

- [ ] формат `webp`
- [ ] размер 1200×1500
- [ ] вес разумный
- [ ] нет текста внутри картинки
- [ ] понятна зона воздействия
- [ ] понятны руки и контакт
- [ ] стрелки читаемые
- [ ] нет анатомических дефектов
- [ ] соответствует карточке по `id`
- [ ] изображение подходит и для `ru`, и для `en`

---

## 12. Дополнительные замечания

### Для `programs`
Для карточек программ сначала можно использовать:

- одну обзорную иллюстрацию с несколькими нейтральными зонами,

или

- временно оставить `image: null`, пока не будут готовы отдельные ключевые визуалы.

### Для `safety`
Для карточек безопасности лучше использовать:

- простые нейтральные схемы,
- иконографические или минималистичные визуалы,
- без драматизации.
